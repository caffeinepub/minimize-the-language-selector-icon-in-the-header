# Specification

## Summary
**Goal:** Enable admins to upload custom Instagram story background images for each travel style archetype and automatically generate personalized Instagram story images with overlaid text when users complete the travel style quiz.

**Planned changes:**
- Add image upload capability in the admin panel Travel Style Quiz section for each travel style archetype
- Extend the Instagram story generator to overlay travel style name and description in Gotham Medium font centered on admin-uploaded base images
- Display the generated Instagram story image in the first tile of the quiz results page with download functionality

**User-visible outcome:** After completing the travel style quiz, users see a custom Instagram story image (1080x1920) with their travel style name and description overlaid on an admin-uploaded background, which they can download and share on Instagram.
