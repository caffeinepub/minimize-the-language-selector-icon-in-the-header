# Specification

## Summary
**Goal:** Refine the Travel Style Quiz finishing/results screen styling so only the three result sections are colored tiles (not a full-width stripe or full-page colored block), with borders consistent with other site tiles.

**Planned changes:**
- Update the finishing/results page layout so “Your Travel Style”, “Your Ideal Destinations”, and “Your Personal Packing List” render as distinct tile/card sections with a filled background.
- Apply the same tile background color currently used by the “Your Ideal Destinations” section to all three tiles, ensuring the color is confined to the tiles (no full-width band/stripe behind them).
- Adjust tile border styling for the three sections to match existing site tile border treatment (consistent color, thickness, radius, and overall look).

**User-visible outcome:** The quiz results screen shows three clearly separated, consistently styled colored tiles for the results sections, with a neutral page background behind them (no full-width colored stripe/block).
